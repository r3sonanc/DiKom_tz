# Учебные копии кода

Это копии текущих исходников с коротким пояснением перед каждой непустой строкой.
Метка `L77` означает строку 77 **оригинального** файла, а не этой копии.
Пустые строки сохранены для читаемости. Исходный код не сокращён и не переписан.

Эти файлы предназначены для чтения. Приложение запускает исходники из корневой
папки `warehouse/`; учебная папка исключена из Docker-контекста.
Маркер `COLCON_IGNORE` также исключает её из поиска пакетов при локальной сборке ROS.
Не запускайте второй диспетчер из копии поверх работающего приложения.
После изменения оригинала его учебную копию нужно обновить.

## Порядок чтения

1. [Путь одной команды](../COMMAND_PATH.md) — объяснения, Firefox и терминалы ROS.
2. [map.py](warehouse/map.py) — точки, рёбра, парковки и расстояния.
3. [robot.py](warehouse/robot.py) — движение, команды, ошибки и мир.
4. [dispatcher.py](warehouse/dispatcher.py) — цели, поиск, занятость, подтверждения.
5. [ros_simulator.py](warehouse/ros_simulator.py) и [transport.py](warehouse/transport.py) — обмен ROS.
6. [api.py](warehouse/api.py) — сервер, проверка HTTP-запросов и снимки состояния.
7. [app.js](warehouse/static/app.js) — кнопки, запросы, WebSocket и canvas.
8. [index.html](warehouse/static/index.html) и [style.css](warehouse/static/style.css) — структура и оформление интерфейса.
9. [warehouse.launch.py](launch/warehouse.launch.py), [setup.py](setup.py),
   [__init__.py](warehouse/__init__.py) — запуск ROS-процессов и сведения о пакете.

Например, найдите `fetch` внутри `request()` в оригинальном `app.js`, затем
метку `L` с текущим номером этой строки в учебной копии: увидите вызов и пояснение.

## Слова Python

| Запись | Что означает |
|---|---|
| `import`, `from ... import` | Подключение модуля или конкретных имён из него |
| `class` | Описание типа объекта: какие у него данные и действия |
| `def` | Определение функции; внутри класса обычно метода |
| `self` | Сам объект, с которым сейчас работает метод |
| `__init__` | Метод начальной настройки нового объекта |
| `self.x` | Поле `x` конкретного объекта |
| `=` / `==` | Присвоить значение / сравнить значения |
| `str`, `int`, `float`, `bool` | Строка, целое, дробное число, логическое значение |
| `True`, `False`, `None` | Да, нет, отсутствие значения |
| `list`, `tuple`, `set`, `dict` | Список, кортеж, множество уникальных значений, словарь ключ → значение |
| `[]`, `{}`, `()` | Форма записи коллекции, индексирования, вызова или группировки — зависит от контекста |
| `dict[str, int]`, `-> bool` | Подсказки о типах словаря и результата; сами по себе не проверяют данные во время работы |
| `str \| None` | Значение может быть строкой или `None` |
| `if`, `elif`, `else` | Выбор ветки по условию |
| `for`, `while` | Перебор элементов / повторение, пока верно условие |
| `in`, `not in` | Проверка наличия элемента, также часть записи цикла |
| `return` | Завершить функцию и вернуть результат |
| `break`, `continue` | Выйти из цикла / перейти к следующему повторению |
| `for ... else` | Ветка `else` выполняется, если цикл завершился без `break` |
| `try`, `except`, `finally` | Попытка действия, обработка исключения, завершающее действие |
| `raise` | Сообщить об ошибке через исключение |
| `with` | Выполнить блок с управлением ресурсом, например с удержанием блокировки |
| `async def`, `await` | Асинхронная функция и ожидание операции с передачей управления циклу событий |
| `lambda` | Короткая безымянная функция, например критерий сортировки |
| `@property` | Метод читается как поле, но при обращении выполняет вычисление |
| `@dataclass` | Декоратор генерирует обычные методы для класса с данными |
| `@staticmethod` | Метод не получает `self`, работает без конкретного экземпляра |
| `*items`, `**fields` | Распаковать последовательность / именованные поля; смысл зависит от места записи |
| `[f(x) for x in items]` | Построить коллекцию преобразованием элементов |
| `f"...{value}..."` | Собрать строку с подстановкой значения |
| `get(key, default)` | Взять значение словаря или запасной вариант, если ключа нет |
| `_name` | Соглашение: внутренняя деталь реализации, не запрет доступа |

## Слова JavaScript и браузера

| Запись | Что означает |
|---|---|
| `const`, `let` | Объявить переменную; `const` запрещает переприсвоить саму ссылку |
| `(x) => ...` | Стрелочная функция |
| `async`, `await`, `Promise` | Асинхронная работа и будущий результат |
| `fetch` | Отправить HTTP-запрос |
| `JSON.stringify`, `JSON.parse` | Объект → JSON-текст / JSON-текст → объект |
| `WebSocket` | Соединение с сервером для сообщений без нового HTTP-запроса на каждый снимок |
| `addEventListener` | Подключить обработчик события: нажатие, сообщение, изменение поля |
| `document`, DOM | Доступ к элементам и структуре страницы |
| `querySelector`, `getElementById` | Найти элемент страницы |
| `$()` в этом проекте | Собственная короткая функция для `document.getElementById`, не jQuery |
| `?.` | Читать поле или вызвать метод, если значение слева не `null`/`undefined` |
| `??` | Подставить запасное значение только для `null`/`undefined` |
| `===`, `!==` | Строгое равенство / неравенство без преобразования типов |
| `&&`, `\|\|`, `!` | И, или, отрицание; первые два могут возвращать сами операнды |
| `...object` | Копировать/распаковать поля объекта или элементы коллекции |
| `condition ? a : b` | Выбрать одно из двух выражений по условию |
| `Map`, `Set` | Коллекция ключ → значение / уникальные значения |
| `canvas`, `ctx` | Полотно для рисования и его 2D-контекст |
| `requestAnimationFrame` | Запросить вызов перед следующим кадром браузера |
| `setTimeout`, `setInterval` | Запланировать отложенный / повторяющийся вызов |

## HTML, CSS и ROS

В HTML тег задаёт элемент, `id` — его идентификатор, `class` — классы оформления,
`data-*` — собственные данные, `aria-*` — сведения для средств доступности.
CSS-селектор выбирает элементы, а пары `свойство: значение` описывают оформление.
`#name` выбирает ID, `.name` — класс; `@media` задаёт правила для условия экрана.

В ROS `publish` отправляет сообщение в топик, `subscription` принимает сообщения,
`callback` — функция обработки события, `timer` вызывает её периодически.
QoS задаёт правила доставки: `RELIABLE` предусматривает надёжную доставку,
`BEST_EFFORT` допускает потери. Даже надёжная доставка не означает, что приказ
уже выполнен роботом: для этого нужна телеметрия.

Lease — ограниченный срок разрешения движения; без продления робот остановится.
Heartbeat — контроль свежести сообщений. `seq` — порядковый номер,
`boot_id` — запуск робота, `world_id` — сцена, `command_id` — приказ перехода.
Подробный пример их совместной работы — в [пути команды](../COMMAND_PATH.md).
